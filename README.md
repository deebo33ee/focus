# جذور — مؤقّت تركيز ومزرعة أصدقاء

تطبيق ويب عربي متجاوب للكمبيوتر والموبايل. اضبط جلسة التركيز والاستراحة، خطط مدة المهمة، ونمِّ أشجارًا متعددة في مزرعتك ومزرعة أصحابك. مزامنة المزارع وحساب Google تستخدم Supabase.

## التشغيل

1. ثبّت Node.js 20.19+ أو 22.12+.
2. شغّل `npm install`.
3. انسخ `.env.example` إلى `.env.local`. أضف عنوان Supabase ومفتاح `anon` (أو `publishable`).
4. افتح SQL Editor في Supabase وشغّل محتوى `supabase/schema.sql`. يضيف الملف حقول نمو الأشجار ويحوّل أشجار البيانات القديمة إلى بلوط حفاظًا على التقدم.
   بعد تحديث المشروع إلى هذا الإصدار، شغّل الملف مرة أخرى لإضافة جداول المهام وصلاحيات أعضاء المزرعة.
5. من إعدادات Supabase Auth فعّل **Allow anonymous sign-ins**. لإبقاء المزرعة التجريبية نفسها عند الربط بحساب Google فعّل **manual identity linking**.
6. لتفعيل Google، أضف Google كمزوّد OAuth في Supabase، واضبط Client ID/Secret ووجّه Google إلى callback الذي يعرضه Supabase. أضف عنوان التطبيق إلى **Redirect URLs** في إعدادات Supabase.
7. شغّل `npm run dev` وافتح الرابط الذي يظهر في الطرفية.

لا تضع مفتاح `service_role` في التطبيق أو ملف البيئة. مفتاح `anon` مصمم للاستخدام في المتصفح، وتقيّده سياسات RLS الموجودة في ملف SQL.

## الاستخدام والمزامنة

- من «الإعدادات» اختر مدة التركيز (١–١٨٠ دقيقة) ومدة الراحة (١–٦٠ دقيقة). المؤقّت يوقف مؤقتًا ويستكمل، والراحة تبدأ بعد جلسة التركيز وتنتقل بعدها للجلسة التالية تلقائيًا.
- أدخل وقت المهمة بالدقائق: يبيّن التطبيق عدد الجلسات والاستراحات، ويقصّر الجلسة الأخيرة لتطابق وقت التركيز المطلوب (مثل ٦٠ دقيقة مع ٢٥ دقيقة للجلسة = ٢٥ + ٢٥ + ١٠ دقائق، واستراحتان).
- اختر نوعًا من ١٢ شجرة. لكل نوع عتبة نمو مستقلة (٣٠ دقيقة إلى ١٠ ساعات)، ويتراكم وقت التركيز المكتمل للشجرة المختارة في مزرعتك، وبالمثل في المزرعة المشتركة عند تفعيل المشاركة.
- أضف مهامًا يومية أو أسبوعية إلى مزرعتك الشخصية أو المشتركة. كل عضو يستطيع إضافة وتعديل مهام المزرعة؛ المهام الرئيسية تتطلب إنجاز الجميع، والمهام المسندة تُسند لأعضاء يختارهم المالك أو المشرف وتُظهر من أكملها.
- اربط حساب Google من الإعدادات لتحويل الحساب المجهول إلى حساب يمكن استعادته. هذا يتطلب إعداد المزوّد والربط اليدوي في Supabase.
- أنشئ مزرعة مشتركة ثم أرسل رابط الدعوة لصاحبينك؛ الحد الأقصى ثلاثة أعضاء.
- يعرض قسم «الأعضاء والصلاحيات» أسماء أعضاء المزرعة. المالك وحده يعيّن المشرفين، والمالك أو المشرف يستطيع إزالة عضو عادي.
- من دون Supabase يعمل المؤقت والمزرعة الشخصية محليًا، لكن الحسابات والمزامنة بين الأجهزة تتطلب مفاتيح Supabase. ومن دون معرّف Microsoft لا يتصل تطبيق To Do.
- بدون إعداد Supabase يعمل المؤقّت والمزرعة الشخصية محليًا للتجربة فقط؛ لا تتزامن البيانات ولا تعمل دعوات الأصدقاء عبر الأجهزة.
- للنشر، استخدم استضافة ثابتة تدعم HTTPS (مثل Vercel أو Netlify)، وأضف متغيرات البيئة في إعدادات الاستضافة وحدّث عناوين التحويل في Supabase وMicrosoft Entra. يلزم HTTPS لتثبيت التطبيق ومشاركة الروابط من الهاتف.
